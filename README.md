# 利用人工智能工具生成 Python 脚本

本项目的目标是证明，在某些情况下，可以利用人工智能（AI）工具实现复杂算法脚本的自动化编写。

## 项目背景

本次我们将重新探讨一个最初于2020年在Developpez.com上开设的“Python Flask 2020”课程中提出的问题。

该课程基于**2019年度的简化税务计算**。当时，为解决该问题，开发人员手动编写了一个Python脚本，随后将其改编为18个不同版本，最终将其实现为一个MVC Web应用程序。

## 目标

本实验旨在证明：截至2025年9月，最初的税务计算脚本可由某些生成式AI系统直接生成，但并非所有系统都能做到。

## 测试的AI工具

本次实验（2025年9月）使用了以下七种工具：

* ChatGPT
* Grok
* Gemini
* MistralAI
* DeepSeek
* ClaudeAI
* Perplexity
